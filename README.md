# my-first-pr

Learning repo for my first pull request.

## What is this?

This repository is a sandbox where I practice the pull request workflow: create a branch, make a change, open a PR, and merge it.


## Pull request workflow

1. Create a branch: `git checkout -b my-branch`
2. Make a change and commit it: `git commit -am "Describe the change"`
3. Push the branch: `git push -u origin my-branch`
4. Open a pull request: `gh pr create`
5. Review the diff, then merge.
